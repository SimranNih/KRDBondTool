# KRDBondTool

I developed this Excel-based tool to analyze bond portfolio risk and optimize hedging using Key Rate Duration (KRD). It allows a portfolio manager or analyst to:

Calculate bond cash flows and derive DV01 for individual bonds.
Compute Key Rate Durations across multiple maturities to identify curve-specific sensitivities.
Construct partial or full hedge allocations targeting specific points on the yield curve.
Assess hedge effectiveness through DV01 and KRD alignment.
Visualize exposures via interactive bar charts.
Run scenario analyses using a built-in VBA engine to stress-test portfolio positions against shifts in key rates.

This tool demonstrates practical expertise in fixed income risk management, curve analytics, and portfolio hedging, as well as the ability to develop robust, reusable analytical solutions for trading and portfolio teams.
